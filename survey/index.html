—Abstract

This literature review synthesizes 285 peer-reviewed publications (2014–2026) on edge-assisted, trust-adaptive misbehavior detection and trusted event dissemination in Vehicular Ad Hoc Networks (VANETs). The review examines trust management models, machine learning-based misbehavior detection, edge/RSU architectures, SDN integration, sensor-based hazard detection, and simulation methodologies.

Key findings reveal that hybrid trust models combining direct observation and indirect reputation achieve 86–95% detection accuracy, while federated learning and blockchain approaches address privacy concerns. However, significant gaps persist in real-world validation, lightweight edge-deployable ML models, adaptive trust mechanisms for dynamic attack scenarios, and integrated frameworks combining trust management with secure event dissemination.

This review identifies critical research opportunities in RSU misbehavior detection, SDN-based resilient control planes, and sensor-fusion approaches for pothole detection, providing a roadmap for developing comprehensive VANET security solutions.

1Introduction

Vehicular Ad Hoc Networks (VANETs) form the communication backbone of Intelligent Transportation Systems (ITS), enabling vehicles to exchange safety-critical information about accidents, congestion, road hazards, and emergency events. However, the open and dynamic nature of VANETs exposes them to diverse security threats, including false data injection, Sybil attacks, message replay, selfish forwarding, and compromised infrastructure nodes. These attacks can have catastrophic consequences, from traffic disruptions to life-threatening accidents.

Trust management and misbehavior detection have emerged as essential security mechanisms to ensure the reliability of disseminated information. Traditional centralized approaches face scalability challenges in highly mobile networks with thousands of vehicles. Recent advances in edge computing, where Roadside Units (RSUs) provide computational resources near the network edge, offer promising solutions for real-time, low-latency misbehavior detection. Additionally, Software-Defined Networking (SDN) architectures enable flexible, programmable control planes that can adapt to evolving attack patterns.

This comprehensive literature review examines the state-of-the-art in edge-assisted, trust-adaptive misbehavior detection and trusted event dissemination in VANETs. We analyze 285 publications spanning trust models, machine learning techniques, edge architectures, SDN integration, sensor-based hazard detection, and simulation methodologies. Our goal is to identify effective approaches, highlight critical gaps, and provide a concrete roadmap for developing integrated VANET security solutions that combine trust management, misbehavior detection, and secure event dissemination.

2.3 Inclusion Criteria

Papers were included if they met the following criteria:

  1. Publication Type: Peer-reviewed journal articles, conference proceedings, or high-quality arXiv preprints
  2. Venues: IEEE, ACM, Springer, Elsevier, and other reputable publishers
  3. Time Period: Published between 2014 and 2026
  4. Validation: Included experimental, simulation, or emulation validation (not purely theoretical)
  5. Relevance: Addressed at least one core topic area (trust management, misbehavior detection, edge computing, SDN, sensor-based detection, or simulation methodologies)

2.4 Exclusion Criteria

Papers were excluded if they:

  1. Lacked experimental or simulation validation
  2. Were purely theoretical without practical implementation considerations
  3. Focused exclusively on cryptographic protocols without trust or detection mechanisms
  4. Were not available in English
  5. Were duplicate publications or earlier versions of included papers

4Annotated Bibliography: Top 20 Most Relevant Papers

4.1 Tariq et al. (2025) – D-CASBR Framework [1]

2025World Electric Vehicle JournalML + Blockchain + Fog

This paper proposes the D-CASBR (Decentralized Consortium Authentication and Security-Based Reputation) framework for V2X networks, integrating hybrid machine learning (ElasticNet and Gradient Boosting) for real-time anomaly detection, consortium blockchain for secure information exchange, and a fog-enabled reputation system for trust management. The framework achieves 95% anomaly detection accuracy with minimal false positives, addressing latency issues and eliminating single points of failure.

Relevance: Provides a comprehensive framework integrating ML-based detection, blockchain-based trust, and fog/edge computing—all core components of our proposed system.

4.2 Zheng et al. (2024) – 2PT-CIDS [2]

2024IEEE Trans. ITSGame Theory + Deep RL

Zheng et al. address the dual challenges of rapid anomaly detection and privacy-preserving notification in VANETs through their two-layer privacy-aware trust evaluation CIDS framework (2PT-CIDS). The system employs game-theoretic information incentive mechanisms (Stackelberg and noncooperative games) and reinforcement learning (reward-shaping double duelling deep Q network, D3QN) to prevent privacy leakage while enhancing detection. The integration of game theory with deep reinforcement learning represents a novel approach to balancing security and privacy in collaborative intrusion detection systems.

Relevance: Demonstrates advanced privacy-preserving mechanisms for collaborative detection, addressing a critical concern in trust-based systems.

4.3 Misbehavior Detection Survey (2022) [3]

2022Research SquareSurvey

This comprehensive survey classifies misbehavior detection schemes for VANETs based on architecture (centralized, distributed, hybrid), approach (cryptographic, trust-based, ML-based), and data characteristics. It highlights that machine learning techniques, particularly using the VeReMi dataset, achieve high accuracy (97–99% for various classifiers), but most techniques lack real-time implementation and suffer from communication overhead due to digital signatures and certificates. The survey identifies the need for compact certificates, data aggregation, and practical real-time deployment.

Relevance: Provides a comprehensive taxonomy of existing approaches, identifies critical gaps (real-time implementation, overhead reduction), and validates the importance of ML-based detection methods.

4.4 Zhang et al. (2021) – AIT System [4]

2021IEEE IoT JournalDeep Learning + Blockchain

The AIT (AI-enabled Trust Management) system combines deep learning for vehicle trust management with blockchain technology for validating reports and enabling RSU-based revocation of untrustworthy vehicles. The system addresses security challenges from erroneous or tampered traffic messages caused by malfunctioning sensors or malicious vehicles. Experimental results show AIT outperforms existing approaches in accuracy and efficiency.

Relevance: Demonstrates the integration of AI/deep learning with blockchain for trust management and RSU-based enforcement.

4.5 Ahmed et al. (2022) – Blockchain-Based Trust Management [5]

2022IET NetworksBlockchain + Trust

Ahmed et al. propose a blockchain-based authentication scheme to protect vehicle identity privacy and a trust management model that evaluates both vehicle and data trustworthiness to detect false information. The dual evaluation approach enables RSUs to broadcast only legitimate events. Simulation validation shows better performance than state-of-the-art models in identifying malicious vehicles.

Relevance: Addresses both authentication and trust management with blockchain, providing insights into privacy-preserving identity management and dual-layer trust evaluation for secure event dissemination.

4.6 Junejo et al. (2020) – Lightweight Trust Model [6]

2020Scientific ProgrammingLightweight Trust + SUMO/OMNeT++

This work proposes a lightweight, attack-resistant trust model using a pseudonym scheme for privacy preservation. The Trust Estimation Model evaluates five parameters: Location Closeness, Data Integrity, Authentication, Time Stamp Verification, and Peer Alert Message. RSUs serve as trusted sources, and a Decision Model processes or discards messages based on a threshold. Evaluated using SUMO, OMNeT++, and VEINS with OpenStreetMap data, the model achieves a 95% F-score with 40% MiTM attackers, outperforming the MARINE system (90% F-score).

Relevance: Demonstrates a practical, lightweight trust model with specific trust parameters and RSU-based trusted infrastructure, validated with realistic simulation tools.

4.7 Abhishek et al. (2019) – RSU Misbehavior Detection [7]

2019ICC ChinaRSU Trust + Threshold

Abhishek et al. address the critical problem of detecting compromised RSUs in vehicular edge computing environments. Their trust-based detection system collects feedback from vehicles about RSU behavior (packet corruption, dropping) and aggregates trust values at a central trusted server for threshold-based classification. The system also includes a mechanism to detect malicious vehicles reporting false feedback.

Relevance: Directly addresses RSU misbehavior detection, a critical gap in most VANET security research that focuses primarily on vehicle misbehavior.

4.8 HDRS (2022) – Hybrid Reputation System [8]

2022IEEE Trans. ITSHybrid Reputation + AHP

The Hybrid Reputation System with Dynamic Update Interval (HDRS) allows separate evaluations by vehicles and RSUs, incorporates a reliability evaluation module to filter unreliable results, and uses a dynamic adjustment mechanism for reputation update intervals based on Analytic Hierarchy Process (AHP) and reliability. HDRS increases detection rates for collusion attacks by 30% and intelligent attacks by 16% compared to existing schemes.

Relevance: Introduces dynamic adaptation mechanisms for reputation updates, addressing the challenge of adapting to evolving attack patterns—a key requirement for trust-adaptive systems.

4.9 Lam et al. (2024) – MEFPB Scheme [9]

2024IEEE IoT JournalDempster-Shafer + Path Backtracking

The Multidimensional Trust Evidence Fusion and Path-Backtracking Mechanism (MEFPB) uses Dempster-Shafer theory to fuse direct trust, indirect trust, and message transmission path as trust indicators. The novel inclusion of transmission path as a trust indicator enables more comprehensive trust assessment. A path-backtracking mechanism identifies and traces malicious behaviors, achieving a high malicious behavior detection rate.

Relevance: Introduces a novel trust indicator (transmission path) and provides a mechanism for tracing attack sources, valuable for forensic analysis and adaptive response.

4.10 Siddiqua et al. (2022) – Malicious RSU Detection [10]

2022JASBSR2R Interaction + NS-3

This work proposes a trust-based scheme for detecting malicious RSUs in edge-enabled VANETs using stable and frequent RSU-to-RSU (R2R) interaction to analyze RSU behavior. It detects alteration of sensor-detected data in beacon content. Evaluated using SUMO, NetEdit, and NS-3 with 25 RSUs and 500 vehicles in a 14×14 km area, the system achieves 92% recall and 86% accuracy, though with a notable False Positive Rate up to 30%.

Relevance: Provides detailed simulation setup and quantitative results for RSU misbehavior detection, including realistic scenarios with varying percentages of malicious RSUs (20–60%) and vehicles (5–20%).

4.11 Zhang et al. (2019) – Fog-Enabled Multiservice Delivery [11]

2019IEEE AccessFog Computing + Trust-Aware Routing

Zhang et al. investigate trust-based multiservice delivery in fog-enabled VANETs with integrated misbehavior detection and tolerance. The system uses fog computing to analyze and store data for evaluating dynamic trust weights based on vehicle attributes. A trust-aware heterogeneous traffic allocation algorithm distributes traffic over multiple routing paths with differential resource allocation for misbehavior tolerance. The system achieves 12–40% higher successful service delivery and 10–20% higher effective network utility.

Relevance: Demonstrates the integration of fog/edge computing with trust-based service delivery and misbehavior tolerance, providing insights into resource allocation strategies.

4.12 Shahariar et al. (2024) – Fuzzy Reward and Punishment [14]

2024IJACSAFuzzy Logic + Markov Chain

This paper addresses "untrue attacks" by trusted drivers and proposes a fuzzy RSU controller that determines rewards or punishments based on incident severity, driver past behavior, and RSU confidence. A Markov chain model captures driver lying characteristics. Evaluated using the Veins simulator, the fuzzy scheme encourages drivers to improve behavior over time, demonstrating the effectiveness of adaptive incentive mechanisms.

Relevance: Introduces behavioral modeling and adaptive incentive mechanisms, which can be integrated into trust management systems to encourage honest reporting.

4.13 Roy et al. (2019) – Edge Cloud-Based Traffic Monitoring [15]

2019N/AEdge Cloud + Privacy Preservation

Roy et al. propose an edge cloud-based privacy-preserving secured decision-making model for traffic monitoring. The system employs a heuristic based on vehicular data (GPS location and velocity) to authenticate traffic-related information and filter malicious vehicles. Validated using VENTOS, SUMO, and OMNeT++ with a simulated cloud environment, the model effectively filters malicious vehicles when at least one non-malicious vehicle is present in the region of interest.

Relevance: Demonstrates edge cloud integration with privacy preservation and provides a practical heuristic for data validation using GPS and velocity information.

4.14 Liu et al. (2021) – Digital Twin Vehicular Edge Network [16]

2021WASADigital Twin + Edge AI

Liu et al. propose a digital twin vehicular edge network (DITVEN) to address time-space limitations in edge computing. The system establishes distributed trust evaluation based on trust chain transitivity and aggregation, and uses local reachability density and outlier factor for time-awareness, and curl/divergence for space-awareness in anomaly detection. This novel approach leverages digital twin technology to overcome edge computing constraints.

Relevance: Introduces digital twin concepts for vehicular networks and provides time/space-aware anomaly detection mechanisms, offering a novel architectural approach for edge-assisted detection.

4.15 CARES (2022) – Context-Aware Trust Estimation [20]

2022ACM Trans. Internet Tech.Transfer Learning + Q-Learning

The Context-Aware Trust Estimation for Realtime Crowdsensing Services (CARES) addresses malicious vehicles propagating false information in vehicular edge networks. It uses transfer learning to quickly obtain accurate trust values without prior vehicle knowledge and employs Q-learning-based dynamic adjustment to detect malicious vehicles and filter untrustworthy input. Extensive simulation studies show CARES outperforms existing schemes in malicious vehicle detection accuracy.

Relevance: Demonstrates the application of transfer learning and reinforcement learning (Q-learning) for adaptive trust estimation in crowdsensing scenarios.

4.16 Alkhalidy et al. (2022) – Fuzzy Logic Malicious Node Detection [22]

2022Future InternetFuzzy Logic + RSU Clusters

Alkhalidy et al. propose a fuzzy logic model for evaluating node trust based on multiple factors. Vehicles are organized into RSU-managed clusters, and RSUs assess node credibility before granting network access, evicting malicious nodes based on trust values. Simulation results show the scheme detects and evicts all malicious nodes over time, reducing the ratio of malicious nodes and increasing data delivery success rates to ideal levels.

Relevance: Demonstrates fuzzy logic for trust evaluation and RSU-based cluster management, providing an alternative to probabilistic trust models.

4.17 Yang et al. (2016) – Affinity Propagation for Anomaly Detection [23]

2016Mobile Info. SystemsClustering + Distributed Supervision

Yang et al. introduce a trust-based anomaly detection scheme using affinity propagation for clustering intelligent vehicles. Cluster heads take responsibility for intracluster trust management, enhanced with a distributed supervising mechanism and a central reputation arbitrator for robustness and fairness. The scheme achieves a detection failure rate below 1%, demonstrating high effectiveness in detecting and filtering abnormal vehicles.

Relevance: Provides insights into clustering-based trust management with distributed supervision and central arbitration, achieving very low failure rates.

4.18 Abhishek et al. (2022) – Trust-Based Adversary Detection in Edge Computing [25]

2022J. Comm. NetworksRSU Gateway + Uplink/Downlink Trust

This work addresses adversaries compromising RSUs to launch selective packet dropping or corruption attacks, increasing latency and impacting delay-sensitive applications. Vehicles report uplink and downlink trust values about RSUs to the RSU gateway, which aggregates these values and compares them against thresholds to classify RSUs. The system also detects malicious vehicles reporting false trust values. MATLAB simulations demonstrate detection performance and the impact of adversary parameters.

Relevance: Provides detailed analysis of RSU adversary behavior and separates uplink/downlink trust evaluation, offering insights into fine-grained trust assessment.

4.19 Blockchain-Based Federated Learning (2022) [28]

2022IEEE Trans. Network Service Mgmt.Federated Learning + Differential Privacy

This paper proposes a blockchain-based federated learning scheme for misbehavior detection, enabling collaborative training across multiple distributed edge devices while ensuring data security and privacy. Differential privacy with the Gaussian mechanism provides strict privacy protection for models on the blockchain. Experimental results show the scheme achieves satisfied accuracy and efficiency for common data falsification attacks.

Relevance: Addresses the critical challenge of privacy-preserving collaborative learning for misbehavior detection, combining blockchain with federated learning and differential privacy.

4.20 Haydari et al. (2022) – RSU-Based Online IDS [30]

2022SensorsOnline ML + Real Traffic Dataset

Haydari et al. propose RSU-based online intrusion detection and mitigation for false data injection and stealthy DDoS attacks. Novel machine learning techniques enable centralized detection and mitigation through RSUs. Evaluated using a traffic simulator and real traffic dataset, the proposed methods achieve 78% improvement in the best case and 27% improvement in the worst case compared to state-of-the-art solutions, with the same false alarm probability.

Relevance: Demonstrates superior detection performance with real dataset validation and addresses both false data injection and DDoS attacks, providing insights into ML-based online detection at RSUs.

5Thematic Synthesis

5.1 Trust Models

Direct Trust Models: Compute trust based on direct observations of node behavior. Junejo et al. [6] propose a five-parameter trust estimation model evaluating Location Closeness, Data Integrity, Authentication, Time Stamp Verification, and Peer Alert Messages. Direct trust models offer simplicity and low computational overhead but are limited by sparse interactions in highly mobile VANETs.

Indirect Trust Models (Reputation-Based): The HDRS system [8] implements a hybrid approach allowing separate evaluations by vehicles and RSUs, with a reliability evaluation module to filter unreliable results. The system dynamically adjusts reputation update intervals based on AHP and reliability metrics, achieving 30% higher detection rates for collusion attacks and 16% higher for intelligent attacks.

Multidimensional Trust Fusion: Lam et al. [9] propose the MEFPB scheme using Dempster-Shafer theory to fuse direct trust, indirect trust, and message transmission path as indicators. The inclusion of transmission path as a trust indicator represents a novel contribution, enabling more comprehensive trust assessment and path-backtracking for malicious behavior tracing.

Context-Aware Trust: The CARES system [20] introduces context-aware trust estimation for real-time crowdsensing services, using transfer learning to quickly obtain accurate trust values without prior vehicle knowledge. Q-learning-based dynamic adjustment enables autonomous detection of malicious vehicles.

Blockchain-Based Trust: Zhang et al. [4] combine deep learning for vehicle trust management with blockchain for validating reports and enabling RSU-based revocation. Ahmed et al. [5] propose blockchain-based authentication alongside a dual trust model evaluating both vehicle and data trustworthiness.

Fuzzy Logic Trust: Alkhalidy et al. [22] employ a fuzzy logic model with multiple factors for trust evaluation in RSU-managed clusters. Shahariar et al. [14] propose a fuzzy RSU controller determining rewards or punishments based on incident severity, driver past behavior, and RSU confidence.

Key Findings: Hybrid trust models combining direct observation with indirect reputation achieve the highest detection rates (86–95% accuracy). Dynamic adaptation mechanisms (HDRS [8], CARES [20]) significantly improve resilience against intelligent and collusion attacks. However, most trust models lack real-world validation and do not adequately address computational overhead in resource-constrained vehicular environments.
5.2 Misbehavior Detection Methods

Machine Learning-Based Detection: The survey [3] highlights that ML techniques achieve 97–99% accuracy using the VeReMi dataset, with MA-CIDS(RF) achieving 97% accuracy and CIDS(SVM) achieving 99% F-measure. Haydari et al. [30] propose novel ML techniques for RSU-based online intrusion detection, achieving 78% improvement over state-of-the-art for false data injection and stealthy DDoS attacks.

Deep Learning Approaches: Zhang et al. [4] employ deep learning for vehicle trust management in the AIT system. Zheng et al. [2] integrate D3QN learning in their 2PT-CIDS framework for privacy-aware anomaly detection and notification enhancement.

Federated Learning for Privacy-Preserving Detection: The blockchain-based federated learning scheme [28] enables collaborative training across distributed edge devices while ensuring data security and privacy. Differential privacy with the Gaussian mechanism provides strict privacy protection, achieving satisfied accuracy and efficiency for common data falsification attacks.

Hybrid ML Approaches: Tariq et al. [1] integrate ElasticNet and Gradient Boosting in the D-CASBR framework for real-time anomaly detection, achieving 95% accuracy with minimal false positives.

Anomaly Detection Techniques: Liu et al. [16] propose time-aware (local reachability density, outlier factor) and space-aware (curl, divergence) anomaly detection in the DITVEN framework. Yang et al. [23] use affinity propagation for clustering-based anomaly detection, achieving a detection failure rate below 1%.

Threshold-Based Detection: Abhishek et al. [7], [25] use aggregated trust values compared against thresholds to classify RSUs as benign or malicious. Junejo et al. [6] implement a Decision Model that processes or discards messages based on a trust threshold.

Game-Theoretic Detection: Zheng et al. [2] employ game-theoretic mechanisms (Stackelberg and noncooperative games) to prevent privacy leakage while enhancing anomaly detection.

Key Findings: ML-based detection methods achieve high accuracy (95–99%) but most lack real-time implementation and real-world validation. Federated learning [28] and privacy-preserving approaches [2] address privacy concerns but introduce computational overhead. Lightweight, edge-deployable ML models remain a critical gap. Most detection systems focus on vehicle misbehavior, with limited attention to RSU misbehavior detection [7], [10], [25].
5.3 Edge/RSU Architectures

Fog-Enabled Architectures: Tariq et al. [1] propose a fog-enabled reputation system in the D-CASBR framework, eliminating single points of failure and addressing latency issues. Zhang et al. [11] use fog computing to analyze and store data for evaluating dynamic trust weights, achieving 12–40% higher successful service delivery and 10–20% higher effective network utility.

RSU-Based Detection: Multiple works leverage RSUs for centralized or semi-centralized detection. Haydari et al. [30] implement RSU-based online intrusion detection and mitigation, achieving superior detection performance with real dataset validation. Roy et al. [15] propose an edge cloud-based privacy-preserving decision-making model using RSUs for traffic monitoring.

RSU Misbehavior Detection: Abhishek et al. [7] propose a trust-based detection system where vehicles provide feedback to a central trusted server about RSU behavior. Siddiqua et al. [10], [13] use stable and frequent RSU-to-RSU (R2R) interaction to analyze RSU behavior and detect alteration of sensor-detected data, achieving 92% recall and 86% accuracy.

RSU-Managed Clusters: Alkhalidy et al. [22] organize vehicles into RSU-managed clusters, where RSUs assess node credibility before granting network access. This hierarchical approach reduces communication overhead and enables scalable trust management.

Digital Twin Vehicular Edge Networks: Liu et al. [16] propose DITVEN to address time-space limitations in edge computing, establishing distributed trust evaluation based on trust chain transitivity and aggregation.

Key Findings: Edge/RSU architectures enable low-latency detection and scalable trust management. Fog-enabled systems [1], [11] achieve higher service delivery rates and network utility. RSU misbehavior detection remains underexplored, with most works assuming trusted RSUs. Digital twin approaches [16] offer promising directions for overcoming edge computing limitations.
5.4 SDN and Control-Plane Resilience

Limited SDN Integration: Among the top 30 papers, explicit SDN integration is notably absent. Most works focus on distributed or semi-centralized architectures without leveraging SDN's programmability for adaptive security policies. This represents a significant gap, as SDN could enable dynamic reconfiguration of trust thresholds, routing policies, and resource allocation in response to detected attacks.

Potential SDN Applications:

  • Dynamic Trust Threshold Adjustment: The HDRS system's [8] dynamic update intervals could be implemented as SDN flow rules, enabling centralized policy management with distributed enforcement.
  • Adaptive Routing: Zhang et al.'s [11] trust-aware heterogeneous traffic allocation could leverage SDN for dynamic path selection based on real-time trust assessments.
  • Isolation of Malicious Nodes: RSU misbehavior detection systems [7], [10], [25] could use SDN to immediately isolate detected malicious RSUs from the network control plane.

Control-Plane Resilience: The literature emphasizes distributed trust evaluation and decentralized architectures to avoid single points of failure [1], [16], but does not explicitly address SDN controller resilience. For SDN-based VANET security, controller placement, replication, and Byzantine fault tolerance are critical considerations not addressed in the current literature.

Key Findings: SDN integration with trust management and misbehavior detection is a critical gap in the literature. The programmability and centralized control of SDN could enable adaptive security policies, dynamic resource allocation, and coordinated response to attacks. However, SDN controller resilience and the trade-offs between centralized control and distributed resilience require further investigation.
5.5 Sensor-Based Pothole Detection

Limited Coverage in Top Papers: Among the top 30 papers, explicit focus on sensor-based pothole detection is minimal. Most works address general misbehavior detection and trust management without specific application to sensor-based hazard reporting.

Sensor Data Validation: Siddiqua et al. [10], [13] include a mechanism to detect alteration of sensor-detected data in beacon content for trust calculation, demonstrating awareness of sensor data integrity issues.

Heuristic-Based Validation: Roy et al. [15] employ a heuristic based on vehicular data like GPS location and velocity to authenticate traffic-related information. While not specifically for pothole detection, this approach demonstrates the use of sensor data for cross-validation of reported events.

Trust-Based Event Validation: The general trust management frameworks [4], [5], [6], [9] could be applied to validate sensor-based pothole reports, but the literature lacks specific evaluation for sensor-based hazard detection scenarios.

Key Findings: Sensor-based pothole detection using accelerometer/IMU data is significantly underrepresented in the VANET security literature. Specific challenges such as sensor noise, calibration differences across vehicles, and distinguishing genuine potholes from other road irregularities are not addressed. This represents a critical gap for practical VANET applications focused on road infrastructure monitoring.

8Gaps and Open Problems

8.1 High Priority Gaps

1. Real-World Validation

Most approaches rely on simulation with synthetic data. Only Haydari et al. [30] validate with real traffic datasets. Real-world deployment and validation with actual vehicular networks are critically needed.

2. Lightweight Edge-Deployable ML Models

While ML-based detection achieves high accuracy (95–99%), most approaches do not address computational constraints of edge devices. Lightweight models optimized for RSU deployment with limited CPU, memory, and energy resources are needed.

3. Integrated Trust Management and Secure Event Dissemination

Current works focus either on trust management or misbehavior detection, but lack integrated frameworks that combine trust-based validation with secure, reliable event dissemination mechanisms.

4. RSU Misbehavior Detection

While vehicle misbehavior detection is extensively studied, RSU misbehavior detection is underexplored [7], [10], [13], [25]. Compromised RSUs pose severe threats as they are trusted infrastructure nodes.

5. Adaptive Trust Mechanisms for Dynamic Attack Scenarios

Most trust models use static thresholds or fixed update intervals. Dynamic, adaptive mechanisms that adjust trust parameters based on detected attack patterns and network conditions are needed. HDRS [8] and CARES [20] make progress but require further development.

8.2 Medium Priority Gaps

6. SDN Integration for Adaptive Security

The literature lacks integration of SDN with trust management and misbehavior detection. SDN's programmability could enable dynamic security policy adaptation, but controller resilience, placement, and Byzantine fault tolerance require investigation.

7. Privacy-Preserving Collaborative Detection at Scale

Federated learning [28] and privacy-aware CIDS [2] address privacy concerns, but scalability to thousands of vehicles and convergence time in highly dynamic networks remain challenges.

8. Sensor-Based Hazard Detection and Validation

Sensor-based pothole detection using accelerometer/IMU data is significantly underrepresented. Specific challenges include sensor noise, calibration differences, and distinguishing genuine hazards from other irregularities.

9. Multi-Attack Scenario Evaluation

Most works evaluate against single attack types. Comprehensive evaluation against multiple simultaneous attacks (e.g., false data injection + Sybil + collusion) is needed.

10. Blockchain Scalability and Latency

Blockchain-based approaches [4], [5], [28] provide strong security guarantees but face scalability and latency challenges. Lightweight blockchain protocols or hybrid approaches are needed for real-time VANET applications.

8.3 Lower Priority Gaps

11. Cross-Layer Security Integration

Most approaches focus on application-layer trust. Integration with lower-layer security (MAC-layer authentication, physical-layer security) could provide defense-in-depth.

12. Standardization and Interoperability

Lack of standardized trust metrics, APIs, and protocols hinders interoperability between different trust management systems and VANET deployments.

13. Long-Term Trust Evolution

Most works focus on short-term trust assessment. Long-term trust evolution, reputation recovery mechanisms, and handling of rehabilitated nodes require further study.

14. Energy Efficiency

While some works mention lightweight designs [6], comprehensive energy efficiency analysis for battery-powered vehicles and solar-powered RSUs is limited.

15. Incentive Mechanisms

Beyond Shahariar et al.'s [14] fuzzy reward/punishment scheme, comprehensive incentive mechanisms to encourage honest reporting and participation in collaborative detection are underexplored.

9Research Questions and Hypotheses

RQ1: Integrated Edge-Assisted Trust-Adaptive Framework

Question: Can an integrated framework combining edge-assisted misbehavior detection, trust-adaptive mechanisms, and secure event dissemination achieve superior performance compared to standalone approaches while maintaining real-time operation?

Hypothesis: An integrated framework leveraging lightweight ML at RSUs for misbehavior detection, dynamic trust threshold adaptation based on detected attack patterns, and trust-based event filtering for dissemination will achieve:

  • ≥95% detection accuracy with ≤5% false positive rate
  • ≤100ms detection latency at RSUs
  • ≥90% legitimate event delivery rate with ≤10% malicious event propagation

RQ2: RSU Misbehavior Detection with R2R Collaboration

Question: Can RSU-to-RSU collaborative trust evaluation with sensor data validation detect compromised RSUs more effectively than vehicle-based feedback approaches?

Hypothesis: R2R collaborative trust evaluation with cross-validation of sensor-detected data will achieve:

  • ≥90% RSU misbehavior detection rate with ≤10% FPR
  • Resilience to up to 30% malicious vehicles providing false feedback
  • Superior performance compared to centralized vehicle feedback approaches [7], [25]

RQ3: Lightweight ML for Edge Deployment

Question: Can lightweight ML models deployed at RSUs achieve comparable detection accuracy to complex deep learning models while meeting real-time latency and resource constraints?

Hypothesis: Lightweight ML models optimized for edge deployment will achieve:

  • ≥90% detection accuracy (within 5% of complex models)
  • ≤50ms inference latency per message
  • ≤100MB memory footprint and ≤50% CPU utilization on commodity RSU hardware

RQ4: SDN-Based Adaptive Security Policies

Question: Can SDN-based dynamic security policy adaptation improve resilience against evolving attack patterns compared to static configurations?

Hypothesis: SDN-based adaptive security policies will achieve:

  • ≥20% improvement in detection rate for intelligent and adaptive attacks
  • ≤200ms policy update latency from attack detection to enforcement
  • Resilience to SDN controller compromise through distributed controller architecture

RQ5: Sensor-Fusion for Pothole Detection and Validation

Question: Can sensor-fusion approaches combining accelerometer, IMU, GPS, and camera data with trust-based validation accurately detect and verify pothole reports?

Hypothesis: Sensor-fusion with trust-based validation will achieve:

  • ≥85% pothole detection accuracy with ≤15% FPR
  • ≥95% filtering of false pothole reports from malicious vehicles
  • Robustness to sensor noise and calibration differences across vehicle types

RQ6: Federated Learning Scalability and Convergence

Question: Can privacy-preserving federated learning for collaborative misbehavior detection scale to thousands of vehicles with acceptable convergence time?

Hypothesis: Optimized federated learning with hierarchical aggregation (vehicle → RSU → cloud) will achieve:

  • Convergence to ≥90% accuracy within 100 training rounds
  • Scalability to ≥1000 vehicles per RSU cluster
  • ≤10% accuracy degradation compared to centralized training

10Suggested Experimental Design

10.1 Datasets

Primary Dataset: VeReMi (Vehicular Reference Misbehavior Dataset) — Labeled misbehavior scenarios including position falsification, speed falsification, and various attack types.

Supplementary Datasets:

  • OpenStreetMap: Real-world road network topology for realistic simulations
  • Real Traffic Traces: If available, use real traffic datasets for validation (e.g., from [30])
  • Synthetic Attack Scenarios: Custom scenarios for RSU misbehavior, pothole report falsification, and multi-attack combinations

10.2 Simulator Setup

Recommended Stack: SUMO + OMNeT++ + VEINS + NS-3

Configuration:

  1. Road Network: Urban scenario: 5km × 5km area with realistic road topology from OpenStreetMap; 30–50 RSUs placed at intersections; RSU communication range: 300–500m
  2. Vehicle Mobility: 500–1000 vehicles with realistic mobility patterns from SUMO; Variable speed: 30–80 km/h; Random trip generation with randomTrips.py
  3. Communication: IEEE 802.11p WAVE for V2V and V2I; Beacon frequency: 1–10 Hz; Message types: Beacon, Event Report, Trust Update
  4. Edge Computing: RSUs with edge computing capabilities (simulated processing delay); R2R communication for collaborative trust evaluation; RSU gateway for centralized coordination (optional)

10.3 Attack Scenarios

1. Vehicle Misbehavior

  • False Data Injection: 10–40% malicious vehicles reporting false events
  • Position Falsification: 10–30% vehicles reporting incorrect positions
  • Sybil Attack: Malicious vehicles creating multiple fake identities
  • Selfish Forwarding: 10–20% vehicles refusing to forward messages

2. RSU Misbehavior

  • Packet Dropping: 10–30% compromised RSUs selectively dropping packets
  • Packet Corruption: 10–20% RSUs corrupting message content
  • False Trust Reports: Compromised RSUs reporting false trust values

3. Multi-Attack & Pothole Scenarios

  • Combination: False data injection + Sybil attack
  • Collusion: Groups of malicious vehicles coordinating attacks
  • Intelligent Attacks: Adaptive attackers adjusting behavior based on detection
  • False Pothole Reports: 20–40% malicious vehicles reporting non-existent potholes
  • Pothole Report Suppression: Malicious vehicles not reporting genuine potholes

10.4 ML Pipeline

Phase 1: Data Collection and Preprocessing

  1. Collect beacon messages, event reports, and trust updates from simulation
  2. Extract features: behavioral, spatial, temporal, network, trust, sensor
  3. Label data: benign vs. malicious based on ground truth
  4. Split data: 70% training, 15% validation, 15% testing

Phase 2: Model Training

  1. Baseline Models: Train Random Forest and SVM on VeReMi dataset
  2. Proposed Models: Lightweight Decision Tree, Lightweight Neural Network (MobileNet-inspired), Online Learning Algorithm (Online RF, Incremental SVM)
  3. Hyperparameter Tuning: Grid search or Bayesian optimization
  4. Model Optimization: Quantization, pruning for edge deployment

Phase 3: Federated Learning (Optional)

  1. Distribute training data across vehicles
  2. Implement hierarchical FL: vehicle → RSU → cloud
  3. Use differential privacy (Gaussian mechanism) for privacy protection
  4. Evaluate convergence time and accuracy vs. centralized training

Phase 4: Model Deployment and Evaluation

  1. Deploy trained models at RSUs in simulation
  2. Evaluate real-time detection performance with attack scenarios
  3. Measure latency, throughput, resource utilization

10.5 RSU Architecture

Proposed Architecture Modules:

  1. Detection Module: Lightweight ML model for real-time misbehavior detection
  2. Trust Management Module: Compute and update trust scores for vehicles and RSUs
  3. Event Validation Module: Validate event reports using trust scores and sensor data cross-validation
  4. Dissemination Module: Broadcast validated events to vehicles
  5. R2R Collaboration Module: Exchange trust information with neighboring RSUs
  6. SDN Interface (Optional): Communicate with SDN controller for policy updates

Implement as OMNeT++ modules or NS-3 applications. Simulate processing delays based on model complexity. Implement message queues and prioritization for real-time operation.
