=========================================================
      EDGETRUST-VANET: HOW TO RUN THE DEMO & PRESENTATION
=========================================================

Follow these simple steps to run your project for a demo or panel presentation.

STEP 1: OPEN YOUR TERMINAL
---------------------------------------------------------
1. Open VS Code or your terminal (PowerShell, Command Prompt, or macOS Terminal).
2. Make sure you are in the project folder:
   cd /Users/mouniksai/Documents/edgetrust-ml   (or your path to edgetrust-ml)

STEP 2: TRAIN & VERIFY THE AI MODELS (Optional - already pre-trained)
---------------------------------------------------------
If you want to show the panel how the models train from scratch:
1. Run this command:
   python scripts/train_unified_pipeline.py

2. Wait ~45 seconds. You will see it print:
   - 5-Fold Stratified Group Cross-Validation on Train Split (Mean: 96.95% ± 1.12%)
   - Training all 17 models across 5 distinct ML families
   - Random Forest wins with 97.74% Weighted F1 and 97.77% Accuracy!
   - LightGBM achieves 97.71% F1 with an ultra-fast 329 microsecond edge latency.

STEP 3: START THE DASHBOARD SERVER
---------------------------------------------------------
This starts the backend Flask server that connects the AI models to the web interface.
1. Run this command:
   python dashboard/app.py

2. You should see:
   * Running on http://127.0.0.1:5000
   (Keep this terminal window open while presenting!)

STEP 4: OPEN IN YOUR BROWSER
---------------------------------------------------------
1. Open Google Chrome, Edge, Safari, or Firefox.
2. Type this URL into the address bar and press Enter:
   http://127.0.0.1:5000

3. IMPORTANT: If you ever see old cached data, press Ctrl + Shift + R (or Cmd + Shift + R on Mac) to force-refresh.

STEP 5: WHAT TO SHOW THE PANEL (2-MINUTE WALKTHROUGH)
---------------------------------------------------------
Walk them through the two main tabs:

A) "🌐 VANET Nodes" Tab (Show Research Rigor First):
   - Click this tab first.
   - Show the 23,970 records dataset (72.9% from authentic VeReMi LuST simulation).
   - Explain that you strictly exclude retrospective attack counters to eliminate data leakage.
   - Show that Random Forest won with 97.74% F1 on 3,539 completely unseen vehicles!
   - Point to the Feature Importance chart: Trust features contribute 55.86% of total predictive power!

B) "🚗 Evaluator" Tab (Show Live RSU Edge Operation Second):
   - Click back to the Evaluator tab.
   - Explain: "This simulates a Roadside Unit (RSU) making real-time safety decisions."
   - Click the purple "Simulate Random" button 4 or 5 times.
   - Point to the Decision Output card:
     * When a normal vehicle passes: Trust is ~0.85, ML predicts Normal -> [ ✅ ACCEPT ]
     * When an attacker passes: Trust drops below 0.40, ML flags Malicious -> [ 🚫 BLOCK ]
   - Point to the Activity Log table at the bottom updating with each vehicle's verdict.

HOW TO STOP THE DEMO:
---------------------------------------------------------
When finished, go back to your terminal and press:
   Ctrl + C
This cleanly shuts down the server.
